## Findings

- **Yearly pace** is its own category, `ASOLD` ("Annual Rate for New Single-family Houses Sold"), not `SOLD` with `seasonally_adj = yes`. `SOLD` only has not-adjusted monthly counts.
- **Average price** is data type `AVERAG` (six letters), not `AVERAGE`.
- **Northeast** is geo code `NO`, not `NE`. The others are `MW`, `SO`, `WE`, `US`.
- `TOTAL`, `NOTSTD`, `UNDERC`, `COMPED` values are in **thousands** of homes; prices are in dollars; `MONSUP` and `MMTHS` are in months.
- Rows with `error_data = yes` are relative standard errors (`E_TOTAL`, `E_MEDIAN`, …) and are skipped.
- **Official quarterly values:** none. Every time period in the file is a month, including for median and average price. So quarterly prices are computed as the average of the 3 monthly values (catalog `quarterlyFallback: "average"`).
- The file lists months that have not been published yet (to the end of the current year) with no rows; they are ignored.
